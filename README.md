# 영수증 보정 프로그램

영수증 사진을 자동으로 원근 보정하고 날짜·금액을 OCR로 추출해 파일명으로 저장하는 Windows 포터블 프로그램입니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **파일 불러오기** | 드래그 앤 드롭 또는 파일 탐색기로 여러 장 동시 선택 |
| **자동 원근 보정** | OpenCV 윤곽선 검출로 영수증 사각형 자동 인식 |
| **수동 원근 보정** | 4개 꼭짓점을 마우스로 드래그해 직접 조정 |
| **OCR** | PaddleOCR(기본) → Tesseract → Windows 내장 OCR 순으로 자동 선택 |
| **날짜·금액 추출** | OCR 결과에서 결제일자·합계금액 자동 파싱, 직접 수정 가능 |
| **영수증 목록** | 색상 코드로 OCR 상태 한눈에 확인, 키보드/엑셀식 편집 |
| **일괄 저장** | 선택 항목 `{날짜}_{금액}.ext` 형식으로 일괄 저장 |
| **압축 저장** | JPEG q=85 / PNG 최대 압축으로 `resize_` 접두어 파일 생성 |
| **클립보드 복사** | 현재 이미지를 Windows 클립보드에 바로 복사 |
| **원본 대체** | 보정된 이미지로 원본 파일 덮어쓰기 |

---

## 사용 방법

### 1. 이미지 불러오기
- 영수증 이미지를 프로그램 창으로 **드래그 앤 드롭**하거나
- 좌측 하단 **[파일 열기]** 버튼으로 여러 파일을 한 번에 선택

### 2. 원근 보정
- **[자동 보정]** — 영수증 테두리를 자동으로 감지해 보정
- **[수동 조정]** — 빨강/주황/초록/파랑 꼭짓점을 마우스로 드래그
- 보정된 이미지를 원본으로 저장하려면 **[보정본으로 원본 대체]**

### 3. OCR 실행
- 목록에서 항목 선택 후 **[선택 항목 OCR 실행]** 클릭
- 날짜·금액이 오른쪽 패널과 목록에 자동으로 채워짐
- 잘못 인식된 경우: 목록 셀을 클릭하거나 `F2` / 숫자키 직접 입력으로 수정

### 4. 저장
- 목록에서 저장할 항목 선택 → **[선택 항목 저장]**
- 날짜·금액이 빈 항목은 저장 전 경고 메시지 출력
- 저장 위치: 원본 파일과 같은 폴더의 `스캔된_영수증/` 하위 폴더
- 파일명 형식: `20241231_15000.jpg`

### 5. 목록 키보드 단축키

| 키 | 동작 |
|----|------|
| `↑` / `↓` | 목록 이동 (이미지 자동 전환) |
| `F2` | 선택한 셀 편집 시작 |
| 숫자 / 문자 | 즉시 입력 모드로 편집 시작 |
| `Tab` | 날짜 ↔ 금액 열 전환 |
| `Enter` | 편집 확정 |
| `Esc` | 편집 취소 |
| `Delete` | 셀 내용 삭제 |

## 설치 방법

### 방법 A — 소스에서 직접 실행 (개발자용)

```bash
# 1. 저장소 클론
git clone https://github.com/bangsegi86/ReceiptToName.git
cd ReceiptToName

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 실행
python receipt_tool.py
```

> **PaddleOCR 별도 설치 불필요** — `requirements.txt`에 포함돼 있습니다.  
> 첫 OCR 실행 시 모델 파일(~100MB)을 자동으로 다운로드합니다.

---

### 방법 B — Windows 단일 exe 빌드

```bash
python build.py
```

`build.py`가 자동으로 수행하는 작업:
1. 필요한 Python 패키지 설치 (PaddleOCR 포함)
2. Tesseract OCR 엔진 설치 (없으면 `winget`으로 자동 설치)
3. 한국어/영어 tessdata 다운로드
4. PyInstaller로 `dist\영수증보정프로그램.exe` 생성

> 빌드된 `.exe`는 설치 없이 어디서나 실행 가능합니다.  
> 단, 첫 OCR 실행 시 PaddleOCR 모델이 `%USERPROFILE%\.paddleocr\`에 다운로드됩니다(인터넷 연결 필요, 이후 오프라인 사용 가능).

## OCR 엔진 우선순위

```
PaddleOCR  →  Tesseract  →  Windows 내장 OCR
  (최고)         (중간)          (폴백)
```

- **PaddleOCR** — 한국어 영수증에 가장 정확. 기울어진 텍스트 자동 보정.
- **Tesseract** — PaddleOCR 설치가 없을 때 사용.
- **Windows OCR** — Tesseract도 없을 때 마지막 폴백 (설치 불필요).

상태 표시줄에 `OCR 완료 (123자 인식, PaddleOCR)` 형태로 사용된 엔진이 표시됩니다.
